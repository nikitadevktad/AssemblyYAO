# 09. Экран отдельной новости

[На главную](../../README.md) 

## Задача

Подготовить получение и отображение полного текста выбранной публикации.

## Что изменилось

- В `ApiService` добавлен запрос `wp-json/wp/v2/posts/{id}`.
- В Repository добавлен метод `getNewsId(id)`.
- В `ui/news/details` созданы `NewsDetailUiState`, `NewsDetailsViewModel` и `NewsDetailsScreen`.

## Как работает код

Экран получает `newsId`. `LaunchedEffect(newsId)` запускает загрузку при первом появлении экрана и при изменении ID.

ViewModel запрашивает публикацию через Repository и сохраняет загрузку, ошибку или объект `News`. Repository проверяет HTTP-ответ и преобразует DTO тем же Mapper, который используется для списка.

`NewsDetailsScreen` выбирает содержимое по состоянию. `NewsDetailsContent` показывает изображение, дату, заголовок и полный текст в прокручиваемой колонке.

Текст сайта преобразуется через `HtmlCompat.fromHtml(...).toString()`. Результат передаётся в `Text` как обычная строка HTML-оформление и интерактивные ссылки этим кодом не сохраняются.
