# 05. Состояние загрузки новостей

[На главную](../../README.md)

## Задача

Связать запрос публикаций с состоянием интерфейса и выбором страницы.

## Что изменилось

Добавлены `NewsUiState.kt` и `NewsViewModel.kt` в `ui/news`.

## Как работает код

`NewsUiState` хранит список публикаций, текущую страницу, общее число страниц и новостей, поисковую строку, признак загрузки, источник данных и текст ошибки.

`NewsViewModel` получает `NewsRepository` через фабрику. Состояние хранится в приватном `_ui` через `mutableStateOf`. Свойство `ui` предоставляет его для чтения интерфейсом.

Блок `init` вызывает `loadNews()`. Метод отменяет предыдущую задачу, запускает корутину в `viewModelScope`, выставляет `isLoading = true` и очищает предыдущую ошибку. Поиск использует задержку 350 мс.

В `try` выполняется запрос текущей страницы и обновляются данные. `CancellationException` передаётся дальше. Остальные ошибки сохраняются в состоянии. Признак `isFromCache` включает офлайн-баннер.

`goToPage(page)` проверяет, входит ли номер в диапазон доступных страниц, обновляет `currentPage` и запускает загрузку. При изменении поисковой строки страница сбрасывается на первую.

## Для чего это нужно

Экран читает готовое состояние вместо выполнения запроса в своей разметке. ViewModel объединяет загрузку данных и действия со страницами.
