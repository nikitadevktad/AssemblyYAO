# 11. Навигация между разделами

[На главную](../../README.md) 

## Задача

Добавить нижнюю панель с четырьмя разделами.Подключить переходы между экранами.

## Что сделано

- Создан `TopLevelDestination`. Для каждого раздела заданы маршрут, название и иконка.
- Добавлен `AppBottomBar` с четырьмя кнопками, подписями и подсветкой выбранного раздела.
- Добавлен обработчик нажатия, который передаёт выбранный раздел наружу.
- Подключена зависимость `navigation-compose`.
- В `AppNavigation` добавлены контроллер навигации, наблюдение за текущим маршрутом и общий `Scaffold`.
- Начато подключение `NavHost` с маршрутом главной страницы.

## Как работает

`TopLevelDestination` хранит описание разделов. По этим данным строятся кнопки нижней панели.

`AppBottomBar` получает выбранный раздел и обработчик нажатия. При нажатии кнопки он передаёт раздел в `AppNavigation`.

`rememberNavController()` создаёт и сохраняет контроллер навигации. Вызов `navigate(destination.route)` выполняет переход по маршруту.

`currentBackStackEntryAsState()` позволяет отслеживать текущий маршрут. По нему определяется, какая кнопка панели должна быть выделена.

`Scaffold` размещает нижнюю панель и содержимое экрана. `NavHost` связывает маршруты с экранами, а `startDestination` задаёт первый открываемый раздел.
