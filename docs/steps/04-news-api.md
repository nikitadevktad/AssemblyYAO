# 04. Получение новостей с сайта

[На главную](../../README.md) 

## Задача

Получать публикации с официального сайта и передавать их интерфейсу приложения.

## Что изменилось

В `app/build.gradle.kts` добавлены зависимости для Retrofit, Gson, OkHttp, Coil и ViewModel в Compose.

В пакете `data` созданы:

- `remote/dto/NewsDto.kt`: структура ответа сайта.
- `remote/api/ApiService.kt`: описание запроса публикаций.
- `remote/retrofit/RetrofitClient.kt`: настройка HTTP-клиента и Retrofit.
- `model/News.kt`: модель публикации для приложения.
- `model/NewsPage.kt`: список публикаций с числом страниц и новостей.
- `mapper/NewsMapper.kt`: преобразование DTO в модель приложения.
- `repository/Repository.kt`: получение и обработка ответа.

## Как работает код

`ApiService.getNews` обращается к `wp-json/wp/v2/posts`. Параметры запроса задают число публикаций, номер страницы и включение вложенных данных через `_embed`.

`RetrofitClient` использует адрес `https://ассамблея76.рф/`. Gson преобразует JSON в DTO. OkHttp выполняет HTTP-запросы, а interceptor записывает запросы и ответы в журнал.

`NewsDto` описывает поля ответа, включая вложенные `rendered` и данные изображения. `NewsMapper.toNews()` извлекает нужные значения. URL изображения берётся из первого элемента `featuredMedia`, если он присутствует.

`Repository.getNews(page)` запрашивает пять публикаций. При успешном ответе он преобразует DTO и читает заголовки `X-WP-TotalPages` и `X-WP-Total`. Если заголовки отсутствуют или не разбираются, используются значения 1 и размер полученного списка.

При неуспешном HTTP-ответе или пустом теле создаётся исключение.

## Для чего это нужно

DTO повторяет структуру ответа сайта. Модель `News` предоставляет данные интерфейсу без обращения к вложенным полям JSON. Repository объединяет запрос, проверку ответа и преобразование данных.
