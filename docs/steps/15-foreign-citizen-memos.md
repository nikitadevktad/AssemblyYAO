# 15. Памятки иностранному гражданину

[На главную](../../README.md)

## Задача

Добавить памятки на главную страницу и экран «О нас».

## Что изменилось

- PDF-файлы добавлены в `res/raw`.
- После новостей добавлен список памяток.
- В «О нас» после «Документы» добавлен раскрываемый раздел «Памятки».
- Добавлены версии на семи языках.
- Для открытия PDF настроен `FileProvider`.

## Как работает код

`ForeignCitizenMemosContent` отображает общий список памяток. При нажатии выбранный PDF копируется в кэш и открывается в системном просмотрщике.
