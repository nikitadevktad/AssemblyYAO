# 13. Экран «О нас»

[На главную](../../README.md) 

## Задача

Показать сведения об организации в раскрываемых разделах.

## Что изменилось

1. Создан экран `AboutScreen`.
2. Цитата вынесена в компонент `AboutQuote`.
3. Создан `AboutSection` для раскрываемого раздела.
4. Добавлено состояние `expanded` и смена стрелки при нажатии.
5. Создан `AboutSectionItem` с иконкой и заголовком.
6. Добавлен список из пяти разделов.
7. Настроено отображение разделов через `forEach`.
8. Настроен выбор содержимого через `when`.
9. Создан `GoalsContent` с описанием и тремя целями.
10. Создан `GoalItem` для оформления одной цели.
11. Создан `StructureContent` с федеральным и региональным блоками.
12. Создан `PersonCard` с фотографией, именем и должностью.
13. Добавлены фотографии представителей организации.
14. Тексты вынесены в `strings.xml`.
15. Добавлена прокрутка в `AboutScreen`.
16. Добавлена настройка CI

## Как работает код

1. `AboutScreen` проходит по списку разделов.
2. Для каждого элемента создаётся `AboutSection`.
3. Передаются иконка, заголовок и содержимое.
4. Пользователь нажимает на стрелку.
5. Значение `expanded` меняется на противоположное.
6. Меняется иконка стрелки.
7. Если `expanded` равен `true`, вызывается `content()`.
8. Содержимое отображается под заголовком.
9. При повторном нажатии содержимое скрывается.
