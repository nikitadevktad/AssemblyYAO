
# Ассамблея ЯО

Android-приложение для Ассамблеи народов Ярославской области. Новости, информация об организации и контакты в одном приложении.

Проект находится в разработке.

## О проекте

Приложение создаётся для чтения новостей Ассамблеи и знакомства с её деятельностью. Интерфейс состоит из четырёх основных разделов.

## Возможности

- Читать новости Ассамблеи. 
- Просматривать фотографии и полный текст публикаций. 
- Переходить между страницами списка новостей. 
- Узнавать о деятельности организации. 
- Находить контакты и связываться с представителями Ассамблеи. 

### Реализовано

- Главная страница с логотипом и баннером.
- Перелистывание изображений и индикаторы слайдов.
- Загрузка списка новостей с сайта.
- Карточки с фотографией, датой и заголовком.
- Постраничная загрузка новостей.
- Получение отдельной публикации по ID.
- Экран для отображения полного текста новости.
- Отображение загрузки и ошибок.
- Цветовая тема, шрифты и иконка приложения.

### Предстоит реализовать

- Навигацию между четырьмя основными разделами.
- Переход из карточки к полной новости.
- Экраны «О нас» и «Контакты».
- Поиск публикаций.
- Сохранение новостей для просмотра без интернета.

## Устройство проекта

Код разделён по ответственности:

- UI: экраны и компоненты на Jetpack Compose.
- ViewModel: управление загрузкой и состоянием экранов.
- Repository: получение данных и обработка ответов.
- Remote: описание API и настройка сетевого клиента.
- DTO: структура данных, полученных от сервера.
- Mapper: преобразование ответа сервера в модели приложения.
- Model: данные, с которыми работает приложение.

Сетевые запросы выполняются через Retrofit и OkHttp. ViewModel запускает загрузку в корутинах и передаёт результат интерфейсу.
